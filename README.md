# Voice-to-Text Professional Platform 🎙️

A lightweight, high-accuracy desktop application for converting voice to text in Persian and English. 
This platform uses an intelligent background proxy tunnel to connect to powerful processing engines, delivering near real-time transcriptions.

## ویژگی‌های اصلی (Key Features)
* پشتیبانی از زبان فارسی و انگلیسی با دقت بسیار بالا
* دارای دیتابیس آفلاین برای ذخیره و مدیریت تاریخچه متن‌ها
* تایپ هوشمند متن دقیقاً در محل قرارگیری نشانگر موس (Cursor)
* دارای ۷ تم گرافیکی متنوع (Dark/Light)
* قابلیت ویرایش دستی و مدیریت خطاهای شبکه

## راهنمای استفاده و راه‌اندازی (How to Use)
برای استفاده از این پلتفرم نیازی به نصب هیچ پیش‌نیازی ندارید، فقط فایل اجرایی را باز کنید. اما توجه به **نکته زیر حیاتی است**:

⚠️ **پیش‌نیاز شبکه:**
این نرم‌افزار برای اتصال به موتور پردازش، از یک تونل شبکه ایزوله استفاده می‌کند. شما **حتماً** باید نرم‌افزار عبور از تحریم (مانند **v2rayN** روی پورت `10808` یا `10809`) را در پس‌زمینه ویندوز خود باز نگه دارید. 
* نیازی به قرار دادن ویندوز روی حالت `Set System Proxy` نیست؛ صرفاً باز بودن نرم‌افزار کافی است.
* اگر هندزفری شما تک‌فیش است و آن را به کیس کامپیوتر متصل می‌کنید، به کابل تبدیل ۱ به ۲ نیاز دارید.
